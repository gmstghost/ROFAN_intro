# 잉크로즈 — 로판 트친소표 메이커

로맨스판타지(로판) 트위터 팬덤을 위한 **트친소표 제작 사이트**입니다.
폼에 정보를 입력하면 오른쪽 카드가 실시간으로 완성되고, 이미지로 저장해서 트위터에 바로 올릴 수 있습니다.

## 파일 구성

```
.
├── index.html   # 페이지 구조 (HTML)
├── style.css    # 전체 스타일
├── script.js    # 폼 입력 처리, 카드 렌더링, 임시저장, 이미지 저장, 트위터 공유 로직
└── README.md    # 이 문서
```

세 파일은 반드시 **같은 폴더**에 있어야 합니다. `index.html`이 상대 경로(`style.css`, `script.js`)로 나머지 두 파일을 불러오기 때문입니다.

## 실행 방법

별도의 빌드 과정이 없는 순수 HTML/CSS/JS 프로젝트라, `index.html`을 브라우저로 열기만 하면 바로 동작합니다.

- **가장 간단히 확인하기**: `index.html`을 더블클릭해서 브라우저로 열기
- **로컬 서버로 띄우기** (이미지 저장 기능까지 테스트하려면 권장):
  ```bash
  cd 프로젝트_폴더
  python3 -m http.server 8000
  # 이후 브라우저에서 http://localhost:8000/index.html 접속
  ```
- **실제 배포**: `index.html`, `style.css`, `script.js`를 그대로 정적 호스팅(GitHub Pages, Netlify, Vercel, Cafe24 등)에 업로드하면 끝입니다. 서버 로직이나 데이터베이스가 필요 없습니다.

## 구현된 기능

폼에서 아래 10가지 항목을 입력/선택하면 카드에 실시간으로 반영됩니다.

1. 닉네임 · 아이디 · 프로필 사진 (사진은 업로드 즉시 카드에 원형으로 표시)
2. 나이 (자유 입력 — 숫자, "20대 초반", "비공개" 등 무엇이든 가능)
3. 주 이용 플랫폼 (카카오페이지 / 시리즈 / 리디북스 / 예스24 / 알라딘 / 교보문고 / 조아라 / 기타, 복수 선택)
4. 접속 시간대 (아침 / 오전 / 오후 / 밤 / 새벽 / 랜덤, 복수 선택)
5. 이별은 (블언블 / 블락 / 언팔, 단일 선택 — 같은 항목을 다시 누르면 선택 해제)
6. 트윗 성향 (일상 / 앓이 / 후기 / 읽타 / 그림 / 글 / 기타, 복수 선택)
7. 좋아하는 작품 (자유 입력, 줄바꿈으로 여러 작품 구분)
8. 지뢰 (자유 입력)
9. FREE (자유 입력)
10. 타장르 (자유 입력)

입력하지 않은 항목은 카드에서 자동으로 숨겨져, 다 채우지 않아도 카드가 어색하게 비어 보이지 않습니다.

### 자동 임시저장 & 초기화

- 폼에 값을 입력할 때마다 0.5초 뒤(디바운스) `localStorage`에 자동으로 저장됩니다. 폼 영역 상단에 "임시저장됨 · 오후 3:12"처럼 마지막 저장 시각이 표시됩니다.
- 페이지를 새로고침하거나 다시 열어도 직전에 작성하던 내용(프로필 사진 포함)이 자동으로 복원됩니다.
- 프로필 사진이 너무 커서 저장 공간을 초과하면, 사진을 제외한 나머지 내용만 저장하고 그 사실을 상태 문구로 알려줍니다.
- **전체 초기화** 버튼을 누르면 확인창을 거쳐 폼 입력값과 임시저장된 데이터가 함께 삭제됩니다.
- 모든 항목이 비어 있는 상태에서는 임시저장 데이터를 남기지 않습니다.

### 이미지 저장 / 트위터 공유

- **이미지로 저장** 버튼: `html2canvas` 라이브러리로 카드를 고해상도(3배 스케일) PNG로 캡처해 다운로드합니다. 캡처 전에 폰트 로딩과 레이아웃이 안정될 때까지 대기하고, `html2canvas` 1.4.1의 그라데이션 배경 관련 버그(0px 캔버스에서 `createPattern` 예외 발생)를 캡처 도중에만 임시로 우회하는 패치가 적용되어 있습니다.
- **트위터 새 글쓰기 열기** 버튼: 워터마크 문구가 포함된 트윗 작성 창을 새 탭으로 엽니다.
- ⚠️ **알아두어야 할 제약**: 트위터 웹 공유 링크(Web Intent)는 보안 정책상 URL만으로 이미지를 자동 첨부할 수 없습니다. 그래서 실제 사용 흐름은 `① 이미지 저장` → `② 트위터 새 글쓰기 열기` → `③ 저장된 이미지를 직접 첨부` 순서이며, 화면에도 이 안내 문구가 표시되어 있습니다. 완전 자동 업로드가 꼭 필요하다면 트위터 API v2 연동(OAuth 인증, 백엔드 서버 필요)이 별도로 필요합니다.

## 커스터마이징

### 사이트 이름 / 링크 변경

`script.js` 최상단의 두 변수를 실제 값으로 바꿔주세요. 워터마크와 트위터 공유 문구에 자동으로 반영됩니다.

```js
var SITE_NAME = "잉크로즈";
var SITE_URL  = "https://gmstghost.github.io/ROFAN_intro/";
```

### 색상 / 폰트 변경

`style.css` 최상단 `:root` 안의 CSS 변수만 바꾸면 전체 배색이 한 번에 바뀝니다.

```css
:root{
  --ink-void: #1B1223;    /* 배경 */
  --plum-deep: #2C1B3D;   /* 카드 그라데이션 시작 */
  --burgundy: #4A1942;    /* 카드 그라데이션 끝 */
  --gold: #C9A227;        /* 포인트 컬러(골드) */
  --gold-light: #E7C767;
  --rose-dust: #D68FA3;   /* 포인트 컬러(로즈) */
  --parchment: #F3E9DC;   /* 본문 텍스트 */
  --muted: #9C8AA5;       /* 보조 텍스트 */
}
```

폰트는 `index.html` 상단 `<link>` 태그에서 Google Fonts(`Gowun Batang`, `IBM Plex Sans KR`)를 불러오고 있습니다. 다른 폰트로 바꾸려면 해당 `<link>`의 폰트 이름과 `style.css`의 `font-family` 값을 함께 바꿔주세요.

### 선택 항목(플랫폼/시간대/성향) 추가·삭제

`index.html`에서 해당 `chip-group` 안의 `<button class="chip" data-value="...">` 를 추가/삭제하면 됩니다. 별도의 JS 수정 없이 자동으로 동작합니다.

### 임시저장 키/저장 주기 변경

`script.js` 상단의 아래 두 값으로 저장 키와 디바운스 시간을 조절할 수 있습니다.

```js
var STORAGE_KEY = "inkrose_trichinso_draft_v1";
var SAVE_DEBOUNCE_MS = 500;
```

## 사용 기술

- 순수 HTML / CSS / JavaScript (프레임워크, 빌드 도구 없음)
- [html2canvas](https://html2canvas.hertzen.com/) 1.4.1 — 카드를 이미지로 캡처
- [Google Fonts](https://fonts.google.com/) — Gowun Batang(제목·카드용 세리프), IBM Plex Sans KR(본문·UI용 산세리프)
- 브라우저 `localStorage` — 입력 중인 내용 자동 임시저장/복원

## 브라우저 지원

최신 Chrome, Edge, Safari, Firefox 기준으로 테스트되었습니다. 이미지 저장 기능은 `html2canvas`가 동작하는 환경(캔버스 API 지원 브라우저)에서, 임시저장 기능은 `localStorage`를 사용할 수 있는 환경(시크릿 모드 등에서는 제한될 수 있음)에서 정상 작동합니다.

## 알려진 제약사항

- 트위터에 이미지 자동 첨부 불가 (위 설명 참고)
- 작품 DB 연동 없음 — "좋아하는 작품" 항목은 자유 텍스트 입력 방식
- 임시저장은 브라우저(기기)별 `localStorage`에 저장되므로, 다른 브라우저나 기기 간에는 동기화되지 않습니다.
- 프로필 사진은 base64로 인코딩되어 저장되므로, 매우 큰 이미지를 사용하면 저장 공간 한도를 초과해 사진 없이 저장되거나 임시저장이 실패할 수 있습니다.
